# ChibiSi Core 1.0

Готовые сборки **ChibiSi Core Lite** и **ChibiSi Core Pro** для Windows 64-бит.

Это бесплатная локальная программа с искусственным интеллектом: работает на вашем компьютере, без обязательной отправки данных в облако.

Сайт: [https://chibisilabs.com](https://chibisilabs.com)
